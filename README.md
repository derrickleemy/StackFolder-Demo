# StackFolder Demo

Public demo and privacy site for StackFolder for GitHub.

- [Open the demo pull requests](https://github.com/derrickleemy/StackFolder-Demo/pulls)
- [Visit the website](https://derrickleemy.github.io/StackFolder-Demo/)
- [Read the privacy policy](https://derrickleemy.github.io/StackFolder-Demo/privacy/)
- [Report a problem](https://github.com/derrickleemy/StackFolder-Demo/issues)

The open pull requests form a six-layer stack so StackFolder can be tested on a public repository without a GitHub token.
